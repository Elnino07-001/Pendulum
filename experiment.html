Pendulum Experiment Bench

A virtual lab pendulum with the imperfections of a real one. The bob is a sphere of real size, so the pendulum is longer than the string. Air drag and pivot friction make the swing die away (you can set how strongly), the simulated student's release angle is off by about ±1°, and the stopwatch is timed by your own clicks. Time the swings, record each trial, then plot any two quantities and fit a line.

The dashed line under the pivot is the timing mark. Start and stop the watch as the bob crosses it, always moving in the same direction. The current amplitude in the corner comes from the protractor.

Set up the apparatus

Damping: air drag ∝ v² (stronger for light bobs) plus linear friction b·θ̇. Set both to 0 for an ideal pendulum.

Stopwatch and counter

time (s)oscillations 0.000

Keyboard: Enter start/stop · Space +1 swing · R reset

  1. Release the bob and let it settle for a few swings.
  2. Start the watch as the bob crosses the mark.
  3. Press +1 each time it returns to the mark moving the same way.
  4. Stop on the last count (10–20 swings works well).

In a quick trial, a simulated student times the swings for you. Their reaction lag is about 0.15 s ± 0.05 s at start and 0.12 s ± 0.06 s at stop. The series uses your current setup and changes only the chosen quantity. Running a series unticks earlier rows, so the fit uses only the new series. Tick or untick “Use” to choose which rows go into the fit.
